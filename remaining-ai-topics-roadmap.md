# AI Engineering — Remaining 39 Topics: Topic-by-Topic Production Roadmap

> **Status: specification, not finished lessons.** This catalog defines what each topic must teach, the demonstrations and diagrams to build, and how to assess understanding. It is deliberately not described as 39 completed modules. Use your existing curriculum topic IDs and authoring schema when converting it into repository content.

## Authoring contract

For each topic, create independently useful lesson Markdown files with progressive explanation (motivation → mechanism → worked trace → implementation when useful → failures/trade-offs), a curated question set with answer rubrics, and links to verified primary references. Make diagrams accessible using alt text. Keep exercises deterministic and executable where applicable. Prefer Python standard library/NumPy for teaching; use SDK/framework dependencies only in dedicated integration topics. Cross-link prerequisite topics rather than repeating their entire material.

## Suggested production waves

**Wave A — Neural networks through prompt design (topics 1–6).** Use detailed math, tensor-shape traces and small executable Python programs.

**Wave B — Retrieval and applications (topics 7–18).** Build a small searchable corpus and use the same dataset to compare retrieval, RAG and agent behavior.

**Wave C — Evaluation, safety and operations (topics 19–31).** Use repeatable test fixtures, traces, mock tools and failure injection; do not run costly models by default.

**Wave D — Model adaptation and advanced engineering (topics 32–39).** Favor mechanism-level walkthroughs and small simulations; avoid pretending GPU-intensive training is necessary for understanding.

## Scope boundaries to preserve

- **Tokenization & Embeddings:** tokens and internal learned token vectors; **Embeddings:** whole-text representations for semantic use cases.
- **LLM API Integration:** basic provider interface; **Structured Output / Streaming AI Systems:** deeper reliability contracts and failure handling.
- **Prompt Engineering:** instruction formulation and empirical testing; **Context Engineering:** selection, packing, authorization and freshness of supplied material.
- **RAG:** pipeline design; **RAG Evaluation:** metrics and error attribution.
- **Agents:** state and execution safety; **Agent Frameworks:** library trade-offs; **MCP:** cross-system protocol boundary.
- **AI Security:** threat models; **Guardrails:** defenses with explicit checks; **Data Privacy:** lifecycle and governance.
- **Model Performance:** inference measurements; **Model Serving:** serving runtime; **AI Deployment:** broader application and infrastructure release.

## Publish gate for each topic

1. The full topic coverage is accounted for, with explicit lesson-to-concept mapping.
2. Examples run in an isolated environment with fixed seeds and no paid model calls by default.
3. Diagrams are legible on mobile and have text alternatives.
4. Answers distinguish simplified intuition from exact implementation behavior.
5. Questions include expected reasoning and errors to watch for; no answer is prematurely exposed in recall mode.
6. Source references are verified and version-specific claims are checked.
7. The repository content compiler and tests pass; existing IDs and progress are preserved.
